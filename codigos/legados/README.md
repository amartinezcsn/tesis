# Código y evidencias anteriores a Rev44

Esta carpeta conserva los pipelines diarios, semanales, PCA/RNN, sus configuraciones, pruebas y la copia de la ejecución del 13 de septiembre. No participan en la ejecución híbrida actual.

Para reproducir las pruebas y emitir pronósticos Rev44, usar `../00_pipeline_hibrido.py`, `../01_normalizacion.py`, `../02_config_hibrido.json`, el paquete `../hibrido/`, `../requirements_hibrido.txt` y `../tests/test_hibrido*.py`. Consultar `../README_hibrido.md` para los comandos.

Los resultados y artefactos de modelos de `../output_hibrido/` y `../outputs/` permanecen en sus rutas para que las emisiones guardadas sigan disponibles.
